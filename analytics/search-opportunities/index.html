Sources, scope & safeguards

Metrics come from an administrator-selected Google Search Console export. Search Console totals may differ between a query report and page report because some searches are anonymised or withheld; this dashboard does not add these totals together. The date selectors are labels for the imported period, not a remote filter. Average position is impression-weighted across included rows. CTR is clicks ÷ impressions.

Protected site analytics remain in Private Analytics. This new view stores no GSC data in GitHub, Cloudflare D1, cookies, localStorage, or a remote endpoint. Clearing or closing the browser tab discards imported rows. To create automatic live updates later, a separate server-side Search Console authorization and private API are required.

2 · Download an encrypted logical archive

This is a supplemental encrypted export of the four application tables above. It excludes short-lived anti-spam rate data and any separate advertising database. Use D1 Time Travel or a full Wrangler SQL export for a complete database recovery.

Encryption: AES-256-GCM; key derived with PBKDF2-SHA256 (310,000 iterations), fresh random salt and IV. All encryption takes place locally in your browser. Losing the passphrase makes the archive unrecoverable.

Verify the database first.

3 · Recovery and verification

Primary recovery: Cloudflare D1 Time Travel can restore the production database to a prior timestamp. It is a destructive operation, so stop writes and record the current bookmark before proceeding. Its retention is plan-dependent.

Independent backup: Use Wrangler to export a complete .sql database snapshot to a private, encrypted location. Periodically restore that SQL to a separate test D1 database and check the row counts.

Encrypted archive check: Use the repository’s offline scripts/verify-slashpromo-archive.mjs utility to decrypt and authenticate the archive without uploading it. It can produce a staging-only SQL file if needed.

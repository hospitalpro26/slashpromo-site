# Emergency Access key backup
Optional ACCESS_JWKS_BACKUP Worker variable: JSON object with issuer (exact configured HTTPS team domain), expires (Unix seconds, at most 24 hours ahead), and keys (public RSA JWKs obtained directly from the configured team's /cdn-cgi/access/certs endpoint over HTTPS). Never accept keys from clients. Used only if live key retrieval fails. Signature and all identity claims remain mandatory. Remove the variable once live retrieval works; refresh only after independently verifying the official endpoint. A stale snapshot can delay key revocation until expiry; use only for short emergency testing. No automatic production activation.
